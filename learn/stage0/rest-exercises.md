> 规则：每题只写三样——**HTTP 方法、路径、状态码**（有分支就写分支，如"成功 200 / 不存在 404"）

## R1　获取当前用户的提示词列表，第 2 页每页 20 条

方法：　get　　　　路径：　/api/prompts?page=2&pageSize=20    状态码：成功-200

## R2　按 ID 获取一条提示词；以及 ID 不存在时返回什么

方法：　 get　　　　路径：/api/prompts/:ID　　　　　　　　状态码：成功-200,找不到—404

## R3　创建一条提示词；以及请求体缺 title 字段时返回什么

方法：　post　　　　路径：　/api/prompts　　　　　　　　状态码：成功-201, 缺 title → 400

## R4　只修改一条提示词的标题

方法：　patch　　　　路径：　/api/prompts/42 + body { "title": "新标题" }　　　　　　　　　状态码：200 / 404

## R5　删除一条提示词

方法：delete　　　　　路径：　　　/api/prompts/:ID　　　　　　　状态码：成功-204

## R6　给一条提示词追加一个已有标签（body 传 tagId）；标签已经打过时返回什么

方法：　post　　　　路径：　　/api/prompts/:id/tags + body { "tagId": 5 } 　　　　　　　　状态码： 201；已打过 → 409

## R7　邮箱 + 密码登录，成功和密码错误各返回什么

方法：　post　　　　路径： /api/auth/login　　　　　　　　　　状态码：200 / 401

## R8　收藏 / 取消收藏一条提示词（要求：同一请求发多少次，效果都一样）

方法：　put　　　　路径：　/api/prompts/:id/favorite　　　　　　　状态码：204（或 200 + 返回状态）

## 开做之前的热身四问（先自己写答案，再对计划文件）

1. PUT 和 PATCH 的区别？POST 和 PUT 的幂等性差异？
部分字段更改，使用patch,是幂等的，全部字段替换，使用put，也是幂等的，post则一般都是新建，是不幂等的；
2. 401 和 403 的区别？
401通常是“登录已过期，跳登录页”；403是“您没有权限执行此操作”
3. 201、204 分别用在什么场景？
新建资源成功通常返回201，“操作成功但没有任何内容可返回”比如删除的时候返回204？
4. 为什么删除接口推荐返回 204 而不是 200？
操作成功但没返回内容，这个时候可以给204状态码进行标识，200一般是有返回给前端内容？
