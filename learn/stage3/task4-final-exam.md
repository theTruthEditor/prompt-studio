### Q3 · 方法论移植

三个月后，同事在 compose 里新增了变量 `APP_NEW_FEATURE` 并写进了他自己的 `.env.prod`，代码 push 上线后网站 502——**这次你没见过这个案子**。说出你排查的前 5 步（按顺序，每步说"敲什么/看什么/推出什么"）。

（你的答案）

->提交把 compose 里 新增了变量APP_NEW_FEATURE
→ 但是将变量写进了自己的配置文件中,服务器上的.env.prod 里没有这个新名字
→ compose 不报错，把缺失变量悄悄插值成空字符串
→ 使用APP_NEW_FEATURE为空 → 数据认证失败（P1000）
→ migrate deploy 失败 → 容器退出 → restart 策略反复拉起反复死
→ caddy 背后无人 → API 502
